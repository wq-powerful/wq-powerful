# 吴倩 · AI 产品经理个人网站

基于 React + Vite 构建的个人品牌门户网站，展示个人履历、项目经验与核心能力。

**在线访问：https://wq-powerful.github.io/wq-powerful/**

## 功能板块

| 板块 | 说明 |
|------|------|
| 首页 | 核心定位与能力标签 |
| 关于 | 从业务现场到方案落地的路径 |
| 优势 | 业务理解 / 方案设计 / 工具应用 / 推进赋能 |
| 项目 | DFM 规则编辑器 / AI 工作助手 / 多行业交付 |
| 方法论 | 进入场景 → 结构化 → 验证 → 沉淀 |
| 赋能 | 培训与文档沉淀 |
| 联系 | 联系方式 |

## 技术栈

- **框架**：React 19 + Vite 8
- **样式**：TailwindCSS 3.4
- **动画**：Framer Motion
- **图标**：Lucide React
- **部署**：GitHub Pages + GitHub Actions

## 本地运行

```bash
npm install
npm run dev
```
